# Tux mordido

`tux-bitten.svg` adapta el icono Tux de Papirus con una máscara SVG transparente
en el lateral derecho. El dibujo original se conserva; solo se añade el mordisco.

Original: Papirus Development Team, `Papirus/48x48/apps/tux.svg`,
